# dkview brand

The mark is a shipping container under a magnifying glass. Inside the lens is a readable status table, with green, amber and red dots for running, starting and failed. It does not use Docker's whale, which is Docker's trademark.

| File | Use |
|---|---|
| `dkview-logo.svg`, `dkview-logo-dark.svg` | Wordmark for light and dark backgrounds |
| `dkview-mark.svg`, `dkview-mark-dark.svg` | Icon, 24 px and up |
| `dkview-icon-16.svg`, `dkview-icon-16-dark.svg` | Pixel-aligned icon for 16 px |
| `favicon.ico` | 16, 32 and 48 px |
| `png/` | Icon at 16 to 512 px, logos at 2x |

Colors: tile `#0F1B2D` (dark `#17263C`), container `#2496ED` / `#5AB2F5` / `#1A6FC2`, lens `#E2E8F0`, dots `#4ADE80` `#FBBF24` `#F87171`.
The wordmark is Inter Display (Bold + Regular), converted to outlines, so no font is needed.
